🔑 Join a room

Enter any IP (and optional port) to create or join a chat room. No backend — the IP+port becomes the room key. Everyone who enters the same key lands in the same room (via BroadcastChannel + optional relay).
• Same IP + port = same room. Different port = different room.
• If you and a friend both enter 1.2.3.4:9000, you'll meet there.
• Messages stay on your device and sync via BroadcastChannel or the relay — no server stores anything.
